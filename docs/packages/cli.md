# @source-repo/rpc-cli

The tooling, built on the library's one distinctive property: the network describes itself.

```
npm install -g @source-repo/rpc-cli
```

- **`extract` / `check`** — read the contract off the TypeScript AST, commit it, and fail a build on a breaking change before it fails a plant.
- **The console** — a browser page that is itself a peer: the peer tree over place and owner, live component panels with per-value quality, write dialogs graded by command semantics, structure and capability chips, traffic taps and problems.
- **One-shot verbs** — `peers`, `describe`, `call`, `watch`, `find <capability>`, `bench`, `diff`, `record`/`replay`, `serve` (stand a fake up from a contract).
- **The MCP server** — the whole network handed to an AI assistant: list, describe, call with local argument validation, find by capability, watch traffic, manage scripts and fakes.
- **A broker and a node runtime** — `source-rpc broker` relays for anything that connects; `source-rpc node` makes a machine scriptable from the network.

Full documentation: the [package README](https://github.com/source-repo/rpc/blob/main/packages/cli/README.md). On npm: [@source-repo/rpc-cli](https://www.npmjs.com/package/@source-repo/rpc-cli). Container images: `ghcr.io/source-repo/rpc-cli`.
